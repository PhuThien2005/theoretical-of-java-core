# 33 - Java Module System

## Can nam

- Module system xuat hien tu Java 9.
- File `module-info.java` khai bao module.
- `requires` khai bao module phu thuoc.
- `exports` khai bao package duoc expose.

## Tu kiem tra

- Module khac package nhu the nao?
- `requires` va `exports` dung de lam gi?
- Vi sao nhieu project backend van chua dung module system?
