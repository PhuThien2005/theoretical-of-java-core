# 19 - JDBC

## Can nam

- JDBC la API Java de lam viec voi database quan he.
- Thanh phan hay gap:
  - `Connection`
  - `PreparedStatement`
  - `ResultSet`
- Nen dung `PreparedStatement` de tranh SQL injection.
- Tai nguyen database can dong dung cach.

## Tu kiem tra

- JDBC driver la gi?
- `Statement` va `PreparedStatement` khac nhau nhu the nao?
- SQL injection la gi?
