# 22 - Functional Interface

## Can nam

- Functional interface co dung mot abstract method.
- Annotation `@FunctionalInterface` giup compiler kiem tra.
- Interface hay gap: `Predicate`, `Function`, `Consumer`, `Supplier`.

## Tu kiem tra

- `Predicate<T>` dung de lam gi?
- `Function<T, R>` khac `Consumer<T>` nhu the nao?
- Functional interface lien quan gi den lambda?
