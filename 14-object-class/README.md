# 14 - Object Class

## Can nam

- Moi class trong Java deu gian tiep hoac truc tiep ke thua `Object`.
- Method hay gap: `toString()`, `equals()`, `hashCode()`, `getClass()`.
- `equals()` va `hashCode()` rat quan trong khi dung `HashSet`, `HashMap`.

## Tu kiem tra

- Vi sao nen override `toString()`?
- Quan he giua `equals()` va `hashCode()` la gi?
- Khi nao `getClass()` huu ich?
