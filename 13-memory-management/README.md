# 13 - Java Memory Management

## Can nam

- Stack thuong chua local variable va call frame.
- Heap chua object.
- Garbage Collector thu hoi object khong con duoc tham chieu.
- Memory leak van co the xay ra neu giu tham chieu khong can thiet.

## Tu kiem tra

- Stack va heap khac nhau nhu the nao?
- Object khi nao co the bi garbage collect?
- `OutOfMemoryError` la gi?
