# 09 - OOP

## Can nam

- Class la ban thiet ke, object la doi tuong cu the.
- Encapsulation: dong goi du lieu va hanh vi.
- Inheritance: ke thua.
- Polymorphism: da hinh.
- Abstraction: truu tuong hoa.
- Interface mo ta kha nang/contract.
- Abstract class dung khi co phan chung va phan bat buoc lop con tu dinh nghia.

## Tu khoa

- `class`
- `object`
- `private`
- `this`
- `constructor`
- `extends`
- `implements`
- `super`
- `abstract`
- `interface`

## Tu kiem tra

- Vi sao field thuong de `private`?
- Constructor dung de lam gi?
- Interface va abstract class khac nhau ra sao?
