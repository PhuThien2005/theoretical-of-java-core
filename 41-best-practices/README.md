# 21 - Clean Code

## Can nam

- Ten bien/method/class nen ro nghia.
- Method nen ngan va lam mot viec chinh.
- Tranh lap code qua nhieu.
- Tranh magic number/string.
- Validate input o bien gioi he thong.
- Code de doc quan trong ngang code chay dung.

## Tu kiem tra

- Ten method tot nen co dac diem gi?
- Khi nao nen tach class/method?
- Comment tot khac comment thua nhu the nao?
