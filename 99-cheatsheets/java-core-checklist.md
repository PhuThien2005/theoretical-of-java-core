# Java Core Checklist

## Nen thuoc

- JVM, JRE, JDK
- Primitive vs reference type
- `==` vs `.equals()`
- `static`, `final`, `this`, `super`
- Constructor
- Overloading vs overriding
- Encapsulation, inheritance, polymorphism, abstraction
- Interface vs abstract class
- List, Set, Map
- Checked vs unchecked exception
- Generic type
- Lambda va functional interface
- Stream pipeline
- Try-with-resources

## Cu phap hay dung

```java
if (condition) {
    // ...
} else {
    // ...
}

for (int i = 0; i < 10; i++) {
    // ...
}

for (String item : items) {
    // ...
}

try {
    // ...
} catch (Exception e) {
    // ...
}
```

## Cau hoi phong van intern/fresher

- Java co phai pass-by-reference khong?
- Vi sao String immutable?
- `ArrayList` va `LinkedList` khac nhau nhu the nao?
- `HashMap` hoat dong y tuong nhu the nao?
- Khi nao can override `equals()` va `hashCode()`?
- `final`, `finally`, `finalize` khac nhau nhu the nao?
- Thread safety la gi?
