# 27 - NIO / NIO.2

## Can nam

- NIO/NIO.2 la API moi hon cho file va I/O.
- `Path`, `Paths`, `Files` la cac class quan trong.
- Co the doc/ghi/copy/move/delete file tien hon IO cu.
- NIO cung co channel, buffer, selector cho bai toan nang cao.

## Tu kiem tra

- `Path` khac `File` nhu the nao?
- `Files.copy()` va `Files.move()` dung khi nao?
- Channel va buffer la gi o muc y tuong?
