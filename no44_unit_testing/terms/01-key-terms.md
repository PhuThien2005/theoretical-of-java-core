# Basic Unit Testing Terms

Use this file when a word in the theory feels too compressed. Each term has meaning, importance, confusion, and a small example.

## JUnit

JUnit is a Java testing framework for writing and running automated tests.

Why it matters: It matters because tests protect behavior during change. A common confusion is testing implementation details instead of observable behavior.

Common confusion: learners often memorize `JUnit` as a word but cannot explain what problem it solves or what rule it changes.

Small example: When reading code, ask: what does `JUnit` change, allow, reject, or clarify?
