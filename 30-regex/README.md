# 30 - Regular Expression

## Can nam

- Regex dung de tim, validate, tach chuoi theo mau.
- Java dung `Pattern` va `Matcher`.
- Ky hieu hay gap: `.`, `*`, `+`, `?`, `[]`, `()`, `^`, `$`, `\\d`, `\\w`, `\\s`.

## Tu kiem tra

- Regex validate email co nen qua phuc tap khong?
- `matches()` va `find()` khac nhau ra sao?
- Vi sao trong Java string hay phai viet `\\d` thay vi `\d`?
