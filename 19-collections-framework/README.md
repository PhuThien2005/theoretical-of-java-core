# 12 - Collections

## Nhom chinh

- `List`: co thu tu, co the trung lap.
- `Set`: khong trung lap.
- `Map`: key-value.
- `Queue`: hang doi.

## Class hay gap

- `ArrayList`
- `LinkedList`
- `HashSet`
- `TreeSet`
- `HashMap`
- `TreeMap`
- `PriorityQueue`

## Can nam

- Chon collection theo nhu cau truy cap, them/xoa, sap xep, trung lap.
- `Comparable` dinh nghia thu tu tu nhien.
- `Comparator` dinh nghia cach so sanh ben ngoai class.

## Tu kiem tra

- `ArrayList` va `LinkedList` khac nhau ra sao?
- `HashMap` co cho key trung lap khong?
- Khi nao can override `equals()` va `hashCode()`?
