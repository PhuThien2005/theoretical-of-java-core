# Enum Terms

Use this file when a word in the theory feels too compressed. Each term has meaning, importance, confusion, and a small example.

## enum constant

An enum defines a fixed set of named constants as a type-safe class-like construct.

## enum constructor

## ordinal

`ordinal` — Returns the zero-based numerical position of an enum constant in its declaration.

## valueOf

`valueOf` — Parses a string and returns the corresponding enum constant, throwing IllegalArgumentException if not found.
