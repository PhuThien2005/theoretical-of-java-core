# 10 - String

## Can nam

- `String` la immutable.
- Noi chuoi nhieu lan nen can nhac `StringBuilder`.
- So sanh noi dung String bang `.equals()`.
- Mot so method hay dung: `length()`, `charAt()`, `substring()`, `contains()`, `trim()`, `split()`, `toLowerCase()`, `toUpperCase()`.

## Tu kiem tra

- Immutable nghia la gi?
- String pool la gi?
- Khi nao dung `StringBuilder`?
