# 08 - Methods

## Can nam

- Method gom access modifier, return type, name, parameter list, body.
- Method co the tra ve gia tri hoac `void`.
- Parameter la bien nhan vao, argument la gia tri truyen vao.
- Overloading la nhieu method cung ten nhung khac parameter.
- Recursion la method goi lai chinh no.

## Mau

```java
public static int add(int a, int b) {
    return a + b;
}
```

## Tu kiem tra

- `return` co tac dung gi?
- Overloading khac overriding nhu the nao?
- Recursion can dieu kien dung vi sao?
