# Annotation Terms

Use this file when a word in the theory feels too compressed. Each term has meaning, importance, confusion, and a small example.

## annotation

An annotation attaches metadata to program elements such as classes, methods, or fields.

## built-in annotation

An annotation attaches metadata to program elements such as classes, methods, or fields.

## meta-annotation

## retention

`retention` — Specifies how long the annotation is retained (SOURCE, CLASS, or RUNTIME).

## target

`target` — Specifies the Java elements (TYPE, METHOD, FIELD, etc.) where the annotation can be applied.
