# 14 - Generics

## Can nam

- Generics giup code type-safe va tai su dung duoc.
- Dung nhieu trong Collections.
- Generic class: `class Box<T>`.
- Generic method: `<T> T getFirst(List<T> list)`.
- Wildcard:
  - `?`
  - `? extends T`
  - `? super T`

## Tu kiem tra

- Vi sao `List<String>` tot hon raw `List`?
- `T` la gi?
- `extends` va `super` trong wildcard khac nhau nhu the nao?
