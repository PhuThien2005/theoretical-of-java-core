# 00 - Setup

## Can nam

- JDK la bo cong cu de viet, bien dich va chay Java.
- `javac` bien dich file `.java` thanh `.class`.
- `java` chay bytecode trong file `.class`.
- IDE phu bien: IntelliJ IDEA, VS Code, Eclipse.

## Lenh co ban

```bash
java -version
javac -version
javac HelloWorld.java
java HelloWorld
```

## Tu kiem tra

- JDK khac JRE nhu the nao?
- Vi sao ten file nen trung voi public class?
- Khi nao can dung IDE, khi nao nen tap chay bang terminal?
