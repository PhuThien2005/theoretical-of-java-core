# 00 - Cài Đặt Môi Trường (Setup)

## Mục Tiêu Học Tập

Sau khi hoàn thành chủ đề này, bạn cần có thể:

- Phân biệt JDK (Bộ Phát Triển Java) và JRE (Môi Trường Chạy Java).
- Biên dịch và chạy chương trình Java bằng công cụ dòng lệnh (`javac` và `java`).
- Hiểu tại sao tên file nguồn Java phải trùng với tên lớp `public`.
- Quyết định khi nào nên dùng terminal thay vì IDE để phát triển Java.

## Thuật Ngữ Chính

- JDK (Java Development Kit) — Bộ Phát Triển Java
- JRE (Java Runtime Environment) — Môi Trường Chạy Java
- JVM (Java Virtual Machine) — Máy Ảo Java
- Compilation — Biên dịch
- Execution — Thực thi
- Bytecode — Mã Bytecode
- `javac`
- `java`
- Public Class — Lớp Công Khai
- IDE (Integrated Development Environment) — Môi Trường Phát Triển Tích Hợp
- Terminal — Dòng Lệnh
