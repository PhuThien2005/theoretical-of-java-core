# Danh Sách Kiểm Tra Java Core (Java Core Checklist)

## Các Khái Niệm Cần Nhớ (Must Know)

- JVM, JRE, JDK
- Kiểu dữ liệu nguyên thủy vs. kiểu dữ liệu tham chiếu (Primitive vs reference type)
- Toán tử `==` vs. phương thức `.equals()`
- Từ khóa `static`, `final`, `this`, `super`
- Hàm khởi tạo (Constructor)
- Nạp chồng vs. Ghi đè (Overloading vs overriding)
- Đóng gói, kế thừa, đa hình, trừu tượng (Encapsulation, inheritance, polymorphism, abstraction)
- Giao diện vs. lớp trừu tượng (Interface vs abstract class)
- List, Set, Map
- Ngoại lệ Checked vs. unchecked (Checked vs unchecked exception)
- Kiểu Generic (Generic type)
- Lambda và giao diện chức năng (Lambda and functional interface)
- Đường dẫn Stream (Stream pipeline)
- Cấu trúc Try-with-resources

## Cú Pháp Hay Dùng (Common Syntax)

```java
if (condition) {
    // ...
} else {
    // ...
}

for (int i = 0; i < 10; i++) {
    // ...
}

for (String item : items) {
    // ...
}

try {
    // ...
} catch (Exception e) {
    // ...
}
```

## Câu Hỏi Phỏng Vấn Intern/Fresher (Intern/Fresher Interview Questions)

- Có phải Java truyền tham chiếu (pass-by-reference) không?
- Vì sao lớp String là bất biến (immutable)?
- Lớp `ArrayList` và `LinkedList` khác nhau như thế nào?
- Ý tưởng hoạt động của `HashMap` là gì?
- Khi nào cần ghi đè (override) `equals()` và `hashCode()`?
- `final`, `finally`, `finalize` khác nhau như thế nào?
- An toàn luồng (Thread safety) là gì?
