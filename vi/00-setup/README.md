# 00 - Cài Đặt (Setup)

## Những Gì Bạn Cần Học

Sau khi học xong chủ đề này, bạn cần có khả năng:

- Phân biệt JDK và JRE.
- Biên dịch và chạy chương trình Java bằng công cụ dòng lệnh (`javac` và `java`).
- Hiểu tại sao tên file nguồn Java phải khớp với tên lớp public.
- Quyết định khi nào dùng terminal hay IDE để phát triển Java.

## Thuật Ngữ Chính

- JDK (Java Development Kit — Bộ Công Cụ Phát Triển Java)
- JRE (Java Runtime Environment — Môi Trường Chạy Java)
- JVM (Java Virtual Machine — Máy Ảo Java)
- Compilation (Biên dịch)
- Execution (Thực thi)
- Bytecode (Mã bytecode)
- `javac`
- `java`
- Public Class (Lớp public)
- IDE (Integrated Development Environment — Môi Trường Phát Triển Tích Hợp)
- Terminal (Dòng lệnh)
