# 35 - Networking

## Can nam

- Java co API lam viec voi URL, socket, HTTP.
- `Socket` dung cho TCP co ban.
- `ServerSocket` lang nghe ket noi.
- `HttpClient` Java 11+ dung de goi HTTP API.

## Tu kiem tra

- TCP va UDP khac nhau o muc y tuong nhu the nao?
- Client va server la gi?
- HTTP request gom nhung phan nao?
