# 05 - Toan Tu

## Nhom toan tu

- So hoc: `+`, `-`, `*`, `/`, `%`
- Gan: `=`, `+=`, `-=`, `*=`, `/=`, `%=`
- So sanh: `==`, `!=`, `>`, `<`, `>=`, `<=`
- Logic: `&&`, `||`, `!`
- Tang giam: `++`, `--`
- Ba ngoi: `condition ? a : b`
- Kiem tra kieu: `instanceof`

## Can nam

- `/` voi so nguyen cho ket qua so nguyen.
- `%` lay phan du.
- `&&` va `||` co short-circuit.
- Nen dung ngoac `()` khi bieu thuc dai de de doc.

## Tu kiem tra

- `i++` va `++i` khac nhau ra sao?
- `&&` khac `&` nhu the nao trong bieu thuc boolean?
- Toan tu ba ngoi nen dung khi nao?
