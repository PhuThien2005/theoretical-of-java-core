# 04 - Bien Va Hang

## Cac loai bien

- Local variable: bien trong method/block.
- Instance variable: bien thuoc object.
- Static variable: bien thuoc class.
- Final variable: bien chi gan mot lan.

## Can nam

- Bien local khong co gia tri mac dinh, phai gan truoc khi dung.
- Bien instance/static co gia tri mac dinh.
- `final` dung de tao bien khong doi.
- Constant thuong viet hoa: `MAX_RETRY`.
- `var` co tu Java 10, chi dung cho bien local.

## Tu kiem tra

- Scope cua bien la gi?
- `static final` thuong dung khi nao?
- Stack va heap khac nhau o muc y tuong nhu the nao?
