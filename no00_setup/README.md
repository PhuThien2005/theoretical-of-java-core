# 00 - Setup

## What You Should Learn

By the end of this topic, you should be able to:

- Distinguish between the JDK and the JRE.
- Compile and execute Java programs using command-line tools (`javac` and `java`).
- Understand why Java source filenames must match their public class names.
- Decide when to use a terminal versus an IDE for Java development.
