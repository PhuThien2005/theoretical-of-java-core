# 45 - Cau Hoi Java Core Hay Gap Khi Phong Van

## Nen on

- JVM, JRE, JDK.
- Primitive vs reference type.
- `==` vs `.equals()`.
- String immutable va string pool.
- OOP: encapsulation, inheritance, polymorphism, abstraction.
- Interface vs abstract class.
- Overloading vs overriding.
- `ArrayList` vs `LinkedList`.
- `HashMap` y tuong hoat dong.
- `equals()` va `hashCode()`.
- Checked vs unchecked exception.
- Generics, lambda, stream.
- Thread, synchronization, race condition.

## Cach hoc

- Moi cau tra loi bang 3 phan: dinh nghia ngan, vi du, loi thuong gap.
- Tu noi lai bang tieng Viet truoc, sau do tap noi bang tieng Anh neu can phong van.
